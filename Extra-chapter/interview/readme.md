# RAG 面试题库

## 背景与动机

All-in-RAG 已系统介绍 RAG 的数据准备、索引、检索、生成与评估流程。本题库将课程中的关键知识整理为可复习、可追问、可持续贡献的面试题，帮助读者检查自己是否真正理解概念、原理与技术取舍。

题目和参考答案可以独立阅读；“课程关联”用于回到主教程进一步学习，不代替题目答案。

## 题库范围

首批收录 35 道题，覆盖分块、嵌入、向量库、混合检索、重排、评估和 Agentic RAG 七个主题。每个主题包含 3 道基础题和 2 道进阶题。

当前只收录基础题和进阶题，不收录依赖特定生产经历的实战题。35 道是首批收录规模，不是固定上限。

## 使用方式

- **按课程顺序学习**：学习对应主线章节后，用题目检查理解是否完整。
- **按主题复习**：直接进入薄弱主题，先口述答案，再对照参考答案和常见误区。
- **模拟问答**：由提问者从基础题开始，根据“延伸追问”继续考察理解深度。

## 难度说明

- **基础**：考察定义、工作原理和核心概念辨析。
- **进阶**：考察方案比较、参数权衡和组件协作。

难度表示题目要求的理解层次，不代表某项技术在真实项目中的实现成本。

## 题目模板

新增题目使用以下结构：

```md
## Q<n>. <问题>

**难度：** 基础 | 进阶

### 考察点

- 面试官希望确认的核心能力。

### 参考答案

- 明确结论或定义。
- 原理、取舍和适用边界。

### 常见误区

- 具体且可辨别的错误理解。

### 延伸追问

- 与本题直接相关的问题。

### 课程关联

- [相关课程章节](相对路径)
```

## 贡献规范

- 在对应主题文件末尾追加题目，并延续该文件编号；不要为插入新题重排已有编号。
- 问题应明确且答案可判定，不收录只替换术语或措辞的近义重复题。
- 交叉主题题目放入其主要考察目标对应的文件。
- 参考答案必须独立说明结论、原理和边界，并包含具体的常见误区。
- 每题必须标注“基础”或“进阶”，并链接最相关的课程章节。
- 课程未覆盖的技术结论应引用官方文档或原始论文；推测或经验性结论必须明确标注。
- 尊重引用与版权规范，不大段复制外部资料。
- 当前不收录实战题；如需增加新的难度类别，应先讨论并同步更新本说明。
